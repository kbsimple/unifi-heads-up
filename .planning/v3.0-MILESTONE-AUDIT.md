### Warnings (non-blocking)

1. **Timezone display (WR-02):** `scheduleEndFromSchedule` parses without `Z` suffix — expiry badge may show incorrect time in non-UTC environments. Does not affect schedule correctness in UniFi.
2. **Generic midnight error toast:** POST returns 400 for midnight-crossing schedules but `SchedulePicker` shows a generic "Unable to set schedule" toast instead of surfacing the specific reason.
3. **`scheduleEnd` missing on `updateFirewallPolicy` return:** The schedule route's response body lacks `scheduleEnd` — but `schedule-picker.tsx` always calls `mutate('/api/firewall')` after POST/DELETE, so the correct value is populated via the list endpoint re-fetch. No visual gap.
