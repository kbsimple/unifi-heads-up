## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/firewall/schedule | Untrusted durationHours and policyId from client |
| browser → DELETE /api/firewall/schedule | Untrusted policyId from client |
| Next.js server → UniFi console | Authenticated via X-API-KEY; self-signed cert bypassed by scoped undici Agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | POST /api/firewall/schedule durationHours | mitigate | Zod schema enforces z.number().int().min(1).max(24) — rejects floats, negatives, oversized durations |
| T-11-02 | Tampering | policyId in POST/DELETE body | mitigate | Zod z.string().min(1); UniFi API returns 404 for unknown IDs — error bubbles to 500 response |
| T-11-03 | Elevation of Privilege | POST/DELETE without session | mitigate | getSession() check at handler entry; returns 401 before any UniFi call |
| T-11-04 | Information Disclosure | UniFi API error message in 500 response | accept | Error message contains no PII; low-value target (home network) |
| T-11-05 | Denial of Service | Rapid repeated POST calls scheduling many rules | accept | UniFi API rate limit (10,000 req/min) is the natural ceiling; no additional throttle needed for single-household use |
</threat_model>
