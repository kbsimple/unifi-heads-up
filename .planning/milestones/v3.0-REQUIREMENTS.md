## v3.0 Requirements — Final Status

### State Storage

- [x] **STA-01**: Server records a bandwidth snapshot (download + upload bytes/s) per client every 60 seconds — **SATISFIED** v3.0 Phase 8
- [x] **STA-02**: Snapshots are persisted in a SQLite database on the server — **SATISFIED** v3.0 Phase 8
- [x] **STA-03**: Records older than 30 days are automatically purged — **SATISFIED** v3.0 Phase 8
- [x] **STA-04**: A background server-side interval drives recording independent of any browser session — **SATISFIED** v3.0 Phase 8

### Starred Firewall Rules

- [x] **STAR-01**: User can star or unstar individual firewall rules — **SATISFIED** v3.0 Phase 9
- [x] **STAR-02**: Starred preferences are stored server-side (accessible from any browser or device) — **SATISFIED** v3.0 Phase 9
- [x] **STAR-03**: Starred rules display a star indicator in the full firewall rules list — **SATISFIED** v3.0 Phase 9
- [x] **STAR-04**: User can filter the firewall rules list to show only starred rules — **SATISFIED** v3.0 Phase 9

### Insights

- [x] **INS-01**: User can view a ranked list of heaviest-traffic devices over a selectable period (7, 14, or 30 days) — **SATISFIED** v3.0 Phase 10
- [x] **INS-02**: User can view hourly activity patterns for a specific device showing which hours it is typically active — **SATISFIED** v3.0 Phase 10
- [x] **INS-03**: Insights are accessible from a dedicated page in the app navigation — **SATISFIED** v3.0 Phase 10
- [x] **INS-04**: User can select a time range (7, 14, or 30 days) that applies to all insight views — **SATISFIED** v3.0 Phase 10

### Scheduling (added mid-milestone as Phase 11)

- SCHED-01: Duration picker (2h/6h/24h) accessible from each firewall card — **SATISFIED** v3.0 Phase 11
- SCHED-02: Selecting duration enables rule and schedules auto-disable — **SATISFIED** v3.0 Phase 11
- SCHED-03: Active schedules display expiry indicator — **SATISFIED** v3.0 Phase 11
- SCHED-04: Schedule survives server restart (persisted in UniFi) — **SATISFIED** v3.0 Phase 11
