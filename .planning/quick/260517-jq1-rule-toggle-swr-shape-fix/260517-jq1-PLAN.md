## Goal

Fix the firewall rule toggle: clicking a switch shows "No firewall rules found" blank state then snaps back. Root cause is a shape mismatch in the SWR optimistic update.

## Root Cause (confirmed)

`rule-toggle.tsx` calls `mutate('/api/firewall', updatedPolicies, { optimisticData: updatedPolicies, ... })` where `updatedPolicies` is `FirewallPolicy[]`.

But `firewall-list.tsx` line 109 reads `data?.policies ?? []` — it expects `{ policies: FirewallPolicy[], timestamp: number }`.

When the cache is set to a plain array, `data?.policies` is `undefined`, `policies` falls back to `[]`, the empty state renders ("No firewall rules found"), then `revalidate: true` fetches the real data and the list snaps back.

## Must-Haves

- [ ] `mutate` call in `rule-toggle.tsx` wraps optimistic data as `{ policies: updatedPolicies, timestamp: Date.now() }`
- [ ] Same shape used for both the data argument and `optimisticData`
- [ ] `RuleToggleProps` updated: instead of receiving raw `policies: FirewallPolicy[]`, receive the full SWR data shape `{ policies: FirewallPolicy[], timestamp: number }` so timestamp is preserved in optimistic update
- [ ] All callers of `RuleToggle` updated to pass the new prop shape
