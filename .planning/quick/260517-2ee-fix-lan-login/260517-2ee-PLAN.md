## Goal

`next dev` and `next start` bind to `localhost` by default in Next.js 13+, making the app
unreachable from other machines on the LAN. Docker already works (ENV HOSTNAME="0.0.0.0").
Fix package.json scripts to match.

## Root Cause

`"dev": "next dev"` and `"start": "next start"` — no `-H` flag means Next.js binds to
`127.0.0.1` only. Requests from `192.168.x.x` never reach the server.

## Fix

- `"dev": "next dev -H 0.0.0.0"`
- `"start": "next start -H 0.0.0.0"`

No cookie or auth changes needed — `createSessionCookieOptions` already has `secure: false`
by default and `sameSite: 'lax'`, which work fine over plain HTTP on a LAN.
