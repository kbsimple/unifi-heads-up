Add a new exported function `getRecentAvgRates` that queries the last N snapshots

```typescript
export function getRecentAvgRates(
  macs: string[],
  window: number
): Map<string, { avgDownload: number; avgUpload: number }> {
  if (macs.length === 0) return new Map()

  const database = getDb()
  const placeholders = macs.map(() => '?').join(',')

  const rows = database.prepare(`
    WITH ranked AS (
      SELECT client_mac, download_bps, upload_bps,
        ROW_NUMBER() OVER (PARTITION BY client_mac ORDER BY recorded_at DESC) AS rn
      FROM snapshots
      WHERE client_mac IN (${placeholders})
    )
    SELECT client_mac, AVG(download_bps) AS avg_download, AVG(upload_bps) AS avg_upload
    FROM ranked
    WHERE rn <= ?
    GROUP BY client_mac
  `).all([...macs, window]) as Array<{
    client_mac: string
    avg_download: number
    avg_upload: number
  }>

  return new Map(rows.map(r => [r.client_mac, {
    avgDownload: r.avg_download,
    avgUpload: r.avg_upload,
  }]))
}
```

Edge cases handled automatically:
- Client with fewer than `window` snapshots: AVG over available rows (correct)
- Client with no snapshots yet (brand new): not included in result → falls back to instant rate in recorder
- Empty macs array: early return with empty Map (guard at top)

Add SNAPSHOT_WINDOW constant and override each client's trafficStatus with the

```typescript
import 'server-only'

import { getUnifiClients } from '@/lib/unifi'
import { insertSnapshots, upsertLatestClients, getRecentAvgRates } from '@/lib/db'
import { calculateTrafficStatus } from '@/lib/unifi/traffic'
import type { NetworkClient } from '@/lib/unifi/types'

export const SNAPSHOT_WINDOW = 2

let started = false

export function startRecorder(): void {
  if (started) return
  started = true

  setInterval(async () => {
    try {
      const { clients } = await getUnifiClients()
      insertSnapshots(clients)

      const avgRates = getRecentAvgRates(clients.map(c => c.mac), SNAPSHOT_WINDOW)
      const smoothed = clients.map((client): NetworkClient => {
        const rates = avgRates.get(client.mac)
        if (!rates) return client
        return {
          ...client,
          trafficStatus: calculateTrafficStatus(rates.avgDownload, rates.avgUpload),
        }
      })

      upsertLatestClients(smoothed)
    } catch (err) {
      console.error('[recorder] snapshot failed', err)
    }
  }, 60_000)
}
```

Key properties:
- SNAPSHOT_WINDOW is exported so it can be read in tests and tuned without touching business logic
- Fallback: if a client has no snapshots yet (new device), `avgRates.get()` returns undefined → client retains its instant trafficStatus (graceful degradation)
- calculateTrafficStatus receives averaged bytes/s → same thresholds, just smoother input
